LNIG creating principles
1. Optimism first: playful, never doom-and-gloom.
2. Every post sells from a different angle, a new reason the product matters, not the same message reworded.
3. Plain, simple English. No English-only idioms; the audience is bilingual.
4. Vary structure and format post to post. No template fatigue.
5. Payoff line and caption carry separate voices, never echoing each other.
